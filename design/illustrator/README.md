# Макеты VetMoment в Adobe Illustrator

Скрипт **`VetMoment-to-AI.jsx`** собирает все макеты проекта в нативные файлы Illustrator (`.ai`):
по файлу на группу экранов, **монтажная область на каждый артборд** (desktop, mobile, состояния) с русскими
названиями, каждый артборд — в отдельном слое. Результат сохраняется в `design/source/`.

| Файл .ai | Что внутри |
|----------|-----------|
| `00-concept.ai` | концепт-борд «Бирка на ошейнике» |
| `00-ui-kit.ai` | UI-кит — 5 монтажных областей |
| `00-brand-logo-sheet.ai` | логотип и правила |
| `00-icon-sheet.ai` | набор иконок |
| `01-home.ai` … `12-states.ai` | макеты экранов — 42 монтажные области |

## Как запустить

1. **Установите шрифты** из `design/fonts/desktop/`: выделите все `.ttf` → правый клик →
   «Установить для всех пользователей» (macOS — двойной клик → «Установить»). Перезапустите Illustrator.
   Шрифты Golos Text и Unbounded распространяются по лицензии SIL OFL (тексты лицензий лежат рядом).
2. В Illustrator: **Файл → Сценарии → Другой сценарий…** (`Ctrl+F12`, на macOS `Cmd+F12`) →
   выберите `design/illustrator/VetMoment-to-AI.jsx`.
3. В окне отметьте нужные макеты (по умолчанию все) и нажмите **«Собрать»**. Можно дополнительно
   сохранить PDF. Сборка всех 16 файлов занимает несколько минут.

Если шрифты не установлены, скрипт предупредит и предложит продолжить с заменой шрифтов.

Работает в Illustrator CS6 и новее, на Windows и macOS.

## Что лежит в папке

| Файл | Назначение |
|------|-----------|
| `VetMoment-to-AI.jsx` | скрипт для Illustrator (ExtendScript) |
| `manifest.js` | список макетов, границы и названия артбордов, нужные шрифты — **генерируется** |
| `svg/*.svg` | копии макетов, подготовленные для импорта в Illustrator — **генерируются** |

Чем `svg/` отличается от исходных `design/**/*.svg`: иконки `<use>` (SVG 2) встроены как обычные группы
с явным цветом, тени `feDropShadow` заменены эквивалентным фильтром SVG 1.1, шрифты указаны
PostScript-именами начертаний (`GolosText-SemiBold`, `Unbounded-SemiBold` …), убран `@import` веб-шрифтов.
Внешний вид совпадает с исходными макетами (проверено попиксельным сравнением рендеров).

## После изменения макетов

Исходники макетов — генератор `design/tools/`. После правок пересоберите всё (SVG, PNG и эту папку):

```bash
node design/tools/build.mjs
```

или только эту папку:

```bash
node design/tools/illustrator.mjs
```

и снова запустите скрипт в Illustrator.

Файлы `design/source/*.ai`, доработанные в Illustrator вручную, по правилам проекта главнее SVG.
Повторный запуск скрипта их **перезапишет**, если не снять галочку «Перезаписывать существующие .ai».

## Ограничения

- Тени импортируются как эффект «Фильтры SVG» — редактируются через «Эффект → Фильтры SVG».
  При желании их можно заменить на «Эффект → Стилизация → Тень».
- Иконки — обычные векторные группы, а не символы Illustrator.
- Скрипт проверен на совместимость с ES3 и на имитации API Illustrator; сам Illustrator в окружении
  разработки недоступен. Если что-то пойдёт не так — окно в конце покажет ошибки по каждому файлу.
