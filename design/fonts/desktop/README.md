# Шрифты для установки в систему (Illustrator, Figma, Word)

Статические TTF-начертания, нарезанные из вариативных шрифтов Google Fonts
([Golos Text](https://fonts.google.com/specimen/Golos+Text), [Unbounded](https://fonts.google.com/specimen/Unbounded)).
Лицензия — SIL Open Font License 1.1 (`OFL-*.txt`). Для сайта используются woff2 из папки выше.

| Файл | PostScript-имя | Где в макетах |
|------|----------------|---------------|
| `GolosText-Regular.ttf` | GolosText-Regular | основной текст |
| `GolosText-Medium.ttf` | GolosText-Medium | подписи, меню |
| `GolosText-SemiBold.ttf` | GolosText-SemiBold | кнопки, акценты |
| `GolosText-Bold.ttf` | GolosText-Bold | цифры, выделения |
| `Unbounded-Medium.ttf` | Unbounded-Medium | заголовки |
| `Unbounded-SemiBold.ttf` | Unbounded-SemiBold | заголовки, суммы |
| `Unbounded-Bold.ttf` | Unbounded-Bold | логотип и крупные заголовки |
