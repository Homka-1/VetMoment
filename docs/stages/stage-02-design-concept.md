# Этап 2. Дизайн-концепция, айдентика, дизайн-токены, UI-кит

Дата: 2026-11-03 · Статус: ✅ готов (ждёт утверждения пользователем)

## Цель этапа
Задать визуальный язык продукта: направление, айдентику, дизайн-токены и UI-кит, по которым
будут нарисованы макеты экранов (этап 3) и свёрстан интерфейс (этапы 7–13).

## Что сделано
- Рассмотрены 3 направления («Бирка на ошейнике», «Тетрадь волонтёра», «Ветклиника»), выбрано
  **«Бирка на ошейнике»** — обоснование в `docs/design/concept.md`, борд `design/concept.svg`.
- Айдентика: логотип (знак — бирка на кольце, на ней лапа с подушечкой-сердцем; слово в кривых),
  варианты для светлого, тёмного и жёлтого фона, отдельный знак, фавикон + PNG 16/32/180/512, лист правил.
- Дизайн-токены `design/tokens.json`: палитра (ink, tag, sky, meadow, 5 тонов состояний), роли цветов,
  шрифты и типографическая шкала, отступы, радиусы, тени, фокус, размеры контролов, сетка,
  брейкпоинты, движение. Проверен контраст WCAG AA, `ink-500` затемнён до `#5B6584`, чтобы приглушённый
  текст проходил 4.5:1 и на `ink-100`.
- Шрифты Unbounded и Golos Text (SIL OFL) скачаны в `design/fonts/` (woff2: cyrillic, cyrillic-ext,
  latin, latin-ext — в latin-ext есть ₸) с готовым `fonts.css`.
- Набор из 39 иконок (сетка 24, линия 2 px): спрайт `design/icons/icons.svg` + лист превью.
- Стиль иллюстраций: геометричные портреты собак и кошек с ошейником и биркой (заглушки фото, пустые состояния).
- UI-кит `design/ui-kit.svg` — 5 артбордов: основы; кнопки и формы; статусы всех enum, слоты выгула,
  выбор дня, прогресс; карточки питомца/сбора/приюта, три пути помощи; навигация (шапка desktop/mobile,
  меню, крошки, пагинация, вкладки), модальное окно, тосты, пустое состояние, скелетон.
- Генератор `design/tools/build.mjs`: строит все SVG из `tokens.json` и рендерит PNG через Playwright.

## Принятые решения
- **Направление «Бирка на ошейнике»**: один узнаваемый мотив (бирка/отверстие) на логотип, бейджи и иллюстрации — вместо декора.
- **Жёлтый = деньги**: `tag-500` только у пожертвований, прогресса сборов, логотипа и активного пункта меню; жёлтая кнопка — только «помочь деньгами».
- **Цвета путей помощи**: небо — забрать, бирка — пожертвовать, луг — погулять.
- **Шрифты** Unbounded (заголовки ≥ 18 px, суммы) + Golos Text (всё остальное) — хорошая кириллица, есть ₸ и казахские буквы, OFL, хранятся локально (работа без интернета, демо-макет этапа 15).
- **Статус передаётся текстом**, цвет вторичен; у слотов дополнительно иконка/пунктир/зачёркивание.
- **Карточки без тени**, с границей; тень `md` — только при наведении, `lg` — модалки и тосты.
- **Фокус** — кольцо 3 px `sky-600` с отступом 2 px у всех интерактивных элементов.
- **Логотип в кривых**, т.к. вставляется через `<img>`, где веб-шрифты не работают.
- **Макеты генерируются кодом** из `tokens.json` (а не рисуются вручную), чтобы токены, UI-кит и будущая вёрстка не расходились; SVG при этом остаются редактируемыми (артборды — группы `artboard-NN-…`, текст — текстом).
- **Название VetMoment сохранено**, альтернативы («Бирка», «Хвосты рядом», «Свои») вынесены на решение пользователя.

## Как проверить
Открыть PNG-превью: `design/png/concept.png`, `design/png/ui-kit-01-foundations.png` … `ui-kit-05-navigation.png`,
`design/brand/png/logo-sheet.png`, `design/png/icon-sheet.png`. Пересобрать (нужны Node, Playwright, Python):
```bash
pip install fonttools brotli
node design/tools/build.mjs
```
Код приложения на этапе не менялся — тесты, Pint и `npm run build` не требуются.

## Известные проблемы и долги
- SVG ссылаются на шрифты через `@import url('fonts/fonts.css')`: в браузере всё рендерится точно, а
  Illustrator/Figma подставят шрифты, только если Unbounded и Golos Text установлены в системе.
- Ширина текста в SVG рассчитана по Chromium; в других редакторах возможны сдвиги в 1–2 px.
- Генератор требует Python (fonttools) для логотипа — это инструмент дизайнера, на запуск сайта не влияет.
- Тёмная тема не проектировалась (не требуется брифом).
