# Дизайн-концепция VetMoment

> Этап 2. Борд: [`design/concept.svg`](../../design/concept.svg) ([PNG](../../design/png/concept.png)).
> UI-кит: [`design/ui-kit.svg`](../../design/ui-kit.svg). Токены: [`design/tokens.json`](../../design/tokens.json), описание — [`tokens.md`](tokens.md).

## Что проектируем

Сервис, где человек помогает приюту домом, деньгами или временем. Главный объект — **анкета
конкретного питомца**: кличка, лицо, характер. Аудитория — горожане 18–55 лет, чаще с телефона,
и перегруженные сотрудники приютов (см. `docs/product/brief.md`). Тон: тёплый, человечный,
доверительный. Деньги и запись на выгул требуют строгости, поэтому «тёплый» не значит «игрушечный».

## Рассмотренные направления

| | Направление | Суть | Почему нет / да |
|---|---|---|---|
| A | **«Бирка на ошейнике»** ✅ | Адресная бирка — знак того, что животное «чьё-то». Тёмно-синий + золото бирки, широкий округлый гротеск, мотив пробитого отверстия в бейджах | Выбрано: сюжет взят из мира животных, а не из шаблонов; даёт одну узнаваемую форму на весь интерфейс; синий и золото перекликаются с цветами Казахстана, не копируя флаг |
| B | «Тетрадь волонтёра» | Крафт-бумага, маркер, рукописные подписи, скотч и полароиды | Живо, но плохо масштабируется на кабинеты и таблицы; рукописное снижает доверие к сборам денег; кириллических рукописных шрифтов с хорошей читаемостью мало |
| C | «Ветклиника» | Белый, бирюзовый, медицинская чистота, пиктограммы | Холодно и казённо; усиливает ложную ассоциацию названия с ветеринарией; неотличимо от сотен сервисов записи |

## Направление A: «Бирка на ошейнике»

**Идея.** У домашнего пса на ошейнике есть бирка: имя и телефон хозяина. У приютского — нет.
VetMoment делает такую бирку каждому животному: имя, характер, кому позвонить. Отсюда:

- **логотип** — круглая бирка на кольце, на ней лапа, у которой главная подушечка — сердце;
- **бейджи статусов** — капсулы с пробитым отверстием слева, как у бирки;
- **цвет акцента** — тёплое золото латунной бирки (`tag-500 #F5B82E`);
- **иллюстрации** — у каждого нарисованного питомца ошейник с жёлтой биркой.

Смелость потрачена в одном месте — в бирке и широком заголовочном шрифте. Всё остальное
спокойное: белые поверхности, тонкие границы, тени только у поднятых элементов.

### Палитра
| Имя | HEX | Роль |
|---|---|---|
| Ночная степь `ink-900` | `#1D2B4F` | текст, основные кнопки, подвал |
| Бирка `tag-500` | `#F5B82E` | пожертвования, прогресс сборов, логотип, активный пункт меню |
| Небо `sky-100/600` | `#E3F2F5` / `#1C7A8C` | путь «Забрать домой», информационные состояния, кольцо фокуса |
| Луг `meadow-100/700` | `#EAF4E6` / `#2F5E2A` | путь «Погулять», слоты выгула |
| Снег `ink-50` | `#F6F8FB` | фон секций и кабинетов |

Сознательно не используем: кремовый фон с терракотой, чёрный фон с кислотным акцентом,
градиенты-«подложки».

### Шрифты
- **Unbounded** (600, 500) — заголовки H1–H4 и крупные суммы. Широкий, округлый, с характером;
  хорошая кириллица; бесплатный (SIL OFL). Не мельче 18 px, только в заголовках.
- **Golos Text** (400–700) — весь текст и интерфейс. Спроектирован под кириллицу, ровный на экранах
  телефонов; есть знак тенге ₸ и казахские буквы (Ә, Қ, Ұ…) — для адресов и названий приютов.

Оба шрифта лежат в `design/fonts/` (woff2 + `fonts.css`) и на этапе 7 подключаются локально,
без Google Fonts — сайт и демо-макет работают без интернета.

### Принципы
1. **Конкретный питомец, а не «животные».** Кличка, лицо и характер — в каждой карточке, сборе, записи.
2. **Деньги всегда жёлтые.** Цвет бирки закреплён за пожертвованиями и прогрессом сборов; жёлтая
   кнопка есть только у действия «помочь деньгами».
3. **Статус — словами.** Цвет только помогает: у бейджа есть текст, у слота — иконка, текст,
   пунктир или зачёркивание (WCAG 1.4.1).
4. **Три пути помощи узнаются по цвету:** небо — забрать, бирка — пожертвовать, луг — погулять.
5. **Без шаблонных приёмов:** нет КАПСЛОКА в подписях, нет нумерации 01/02/03 там, где нет
   последовательности, нет стрелок «→» в кнопках, нет анимации «всплытия» каждой секции.

### Иллюстрации и фото
- Иллюстрации — геометричные портреты из простых фигур, без контура, шерсть в 2–3 тонах,
  обязательно ошейник с биркой. Ими закрываем места без фото: заглушки, пустые состояния, 404.
- Фото питомцев (загружают приюты) — в рамке со скруглением `radius-md` 16 px внутри карточки,
  `object-fit: cover`, фон-подложка из светлых цветов путей (`sky-100`, `tag-100`, `meadow-100`).
- Цвета шерсти иллюстраций — вне токенов интерфейса: карамель `#D39A5B`/`#A86B34`,
  крем `#F1DDBF`, графит `#3B3330`, дым `#9AA1AB`/`#6E7581`, рыжий `#E08A3C`.

### Иконки
Собственный набор из 39 иконок (`design/icons/icons.svg`, превью `design/png/icon-sheet.png`):
сетка 24, линия 2 px, скруглённые концы, `currentColor`. Включает предметные: лапа, бирка, поводок,
тенге, прививки, кошка, собака, проверенный приют. Имена иконок = будущий `<x-icon name="…">`.

## Айдентика

### Название
Пользователь ранее предложил сохранить **VetMoment**; логотип сделан с ним. Замечание: «Vet»
читается как «ветеринария», а сервис не про лечение. Альтернативы на выбор (логотип перестраивается
заменой слова, знак остаётся):

| Вариант | Комментарий |
|---|---|
| **VetMoment** (текущее) | знакомо команде, домен/репозиторий уже так называются |
| **Бирка** | прямо из концепции, коротко, по-русски, легко запомнить |
| **Хвосты рядом** | про приюты «рядом с тобой» и выгул |
| **Свои** | «я свой» — про то, что у каждого животного должен быть человек |

### Логотип
Файлы — `design/brand/`:
- `logo.svg` — основной (на светлом), `logo-inverse.svg` — на `ink-900`, `logo-on-tag.svg` — на жёлтом
  (бирка становится белой);
- `logo-mark.svg` — знак отдельно; `favicon.svg` — фавикон без кольца, отверстие точкой;
- `png/` — растровые версии (логотип @4x, фавиконы 16/32/180/512), `png/logo-sheet.png` — лист правил.

Слово набрано Unbounded SemiBold и переведено в кривые (логотип вставляется как `<img>`, где
веб-шрифты не работают). Охранное поле — высота кольца бирки со всех сторон. Минимальная высота
логотипа — 24 px, фавикона — 16 px.

## Файлы и как их пересобрать

Все SVG UI-кита, концепта, иконок и логотипа генерируются скриптом из `design/tokens.json`,
поэтому токены и макеты не расходятся:

```bash
pip install fonttools brotli
node design/tools/build.mjs
```

Нужны Node 20+, Playwright с Chromium и Python 3 — только дизайнеру/агенту, не для запуска сайта.
SVG открываются в Illustrator / Figma / Inkscape: артборды — группы `artboard-NN-…`, текст — текстом
(для правок установите шрифты Unbounded и Golos Text с Google Fonts). Если SVG правят вручную
в Illustrator, исходник кладётся в `design/source/` и становится главнее сгенерированного.
